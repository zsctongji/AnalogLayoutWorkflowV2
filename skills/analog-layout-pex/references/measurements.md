# Measurement contract

Adopt the existing testbench's valid definitions. Fill missing definitions before claiming measurements; ask only for choices that cannot be obtained from saved ADE/OCEAN configuration. Keep supply, VCM, bias, load, device/model and RC corner, temperature and sweep range visible. Distinguish measured values, extrapolations and unavailable results. Do not invent acceptance thresholds.

| Metric | Required analysis and definition | Invalid shortcut |
|---|---|---|
| Gain | AC small-signal transfer H=Vout/(VINP−VINN) at a valid bias point; specify output reference and normalization. DC gain needs operating-point/low-frequency plateau evidence; 20log10(abs(H)) is dB. | Divide by one input while both are driven; report first sample as DC without checking plateau. |
| Bandwidth | Define relative −3 dB bandwidth and separately unity-gain bandwidth. Track all crossings, peaking and tested range; absent crossings are unresolved/unbracketed, not zero. | Equate bandwidth and UGBW or extrapolate beyond sweep silently. |
| Phase margin | Valid negative-feedback loop return ratio (e.g. Spectre stb with correctly placed probe), preserved loading/DC bias and confirmed sign. Report all relevant unity crossings and conventional signed margins; assess multiple crossings rather than picking a flattering one. | Use arbitrary open-loop signal-transfer phase as loop margin, subtract magnitudes, or claim stability from a single positive margin in a multi-crossing loop. |
| Static current | DC at accepted input/output state. Save voltage-source currents; document Spectre sign, supply totals, separate externally injected bias currents and avoid double counting. | Measure switching current or silently omit bias branches. |
| Output swing | Define valid output range under stated load/bias/feedback and a user/TB-defined linearity, distortion or operating-region criterion. Record Vmin/Vmax and Vpp. | Treat a rail-to-rail DC sweep as usable linear swing; invent a 1%/THD cutoff. |
| Input offset | Nominal deterministic DC input difference needed for a specified balanced/target output under fixed VCM/bias/load, using a qualified sweep/servo and bracketing/convergence. Establish sign. | Use Vout/A on saturated output, invent target output, or label deterministic extracted asymmetry as mismatch sigma. |
| Noise | Valid noise analysis at the same bias with explicit input reference/output and source. Report output/input-referred density in V/sqrt(Hz) or PSD in V²/Hz, frequency curve and integrated RMS only over a defined band. Spectre PNoise is a different periodic workflow requiring explicit scope. | Integrate amplitude density directly, confuse PSD with ASD, drop resistor thermal noise or report RMS without frequency band. |

Normalize differential excitation explicitly (for example +0.5/−0.5 yields 1 V differential small signal, if used by the adopted TB). Preserve common-mode AC excitation rules; do not silently convert existing sources. For input-referred noise obtained from output PSD, divide by the actual differential transfer power gain |H|² at the same frequencies; report near-zero/invalid transfer regions. Integrate PSD versus linear frequency, not versus log-frequency; take square root after integration.

PEX integrity checks before simulation: positive finite physical R/C (special model elements handled explicitly), declared units, correct terminal order/escaping, no incomplete include chain, device model/subckt compatibility, preserved intended C1 capacitance and no double count of intrinsic device capacitance, retained coupling/supply/body network scope. Zero or small parasitic count requires evidence, not automatic success. Record reduction thresholds and parasitic corner independently from transistor corner. RC extraction is not an instruction to remove coupling capacitors.

Do not force all analyses into one TB if the topology requires separate stability/offset/swing variants. Existing DUT/stimulus edits require run-local variants and clearly recorded changes. If the model is saturated/nonlinear at the requested bias, retain DC evidence and classify invalid AC/noise/PM rather than fabricate a number. A failed/noisy/non-convergent analysis remains visible even when another metric succeeds.
