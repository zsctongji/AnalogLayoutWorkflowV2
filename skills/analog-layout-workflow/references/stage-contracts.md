# Stage interfaces and minimum rollback

The dispatcher selects executors/scope and maintains evidence continuity; this is not a new database writer. Each skill retains its native artifact schema and rule authority. When native artifacts are missing, reconstruct/verify them from the complete current database first, rather than fabricating the expected schema.

## Special handoffs

analog-layout-local-access owns gate-access. Prefer native Virtuoso contact/via commands bound to current layout hotkeys, then read back actual cuts/landings. Use the rectangle kernel for supported candidate/rule checks. Obtain terminal islands from align/place, check guard-ring gate-access and route contact_landings contracts, and reuse qualified live adapters; read their relevant references as needed. Missing corresponding creation/readback capabilities or contact/via recipes yield BLOCKED_CAPABILITY. Write only user-authorized legal contacts/local escapes, without changing W/L/nf/nets. Assign explicit owners to actual shapes and via roots for complete-macro movement; do not move native-via generated geometry twice. Top-level access geometry now exists, so subsequent stages cannot use a PCell-only importer that fails to preserve those objects.

Internal source-sharing instructions may require place refinement; this is not a second independent initial placement. After guard rings, symmetry/opt must clone completely/move rigidly. After routing, freeze blocks coupled by cross-module wires unless rerouting/reconnection is authorized.

Use symmetric-fast by default when no routing method is selected; explicit symmetric-route requests use joint search and explicit general requests use route. Record the backend and selection reason. Neither template selection nor joint-search success proves global live reflection automatically. Apply strict reflection only to cores with corresponding geometric/electrical identities. Classify shared/bias/self nets and additional output branches separately. Non-axis structures use general route or matched_only, without fabricated mirrored devices. Both paths share original route checks/import; select one main planning strategy.

DC current, temperature/model/RC corners and TB stimuli come from the actual testbench or user decisions, not design names or other runs. Missing definitions suspend only the corresponding metric: without a noise band, output density without integration; without a swing criterion, do not claim valid swing; without an offset target, do not infer offset from VOUT/A.

## Check/repair closure

DRC and LVS may share fingerprint-verified stream/export artifacts but cannot replace independent conclusions with one overall PASS. Check bindings/integrity/severe warnings first; export errors do not justify geometric changes. LVS opens/shorts/wrong devices block PEX performance interpretation. DRC-only deferrals may permit exploratory PEX after explicit user acceptance of limitations, without a signoff claim.

After every physical repair, check the axis, all mates even without markers, actual metal/cuts/landings and access. Connectivity changes require independent LVS, and geometric changes require DRC with the same rules; route/contact/ring repairs in this workflow usually require both. If LVS export configuration is corrected without OA changes, rerun only affected checks, without unnecessary rerouting.

This dispatcher does not automatically require multiple agents or the full circuit pipeline. Actual simulation follows current analog-pipeline/analog-verify verifier-ownership rules. If delegation applies, explicitly restrict it to execution/reporting and prohibit verifier edits to .scs. Do not start simulations while creating skills or planning candidates.
